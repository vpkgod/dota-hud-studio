# Проверка в настоящей Dota

`./tools/ingame/check.sh tools/ingame/scenarios/tester.json juggernaut kez`

1. Собирает мод из сценария тем же кодом, что и сайт (`build_mod.mjs`).
2. Снимает превью сайта 1920×1080 без настроек и с настройками (`preview_shot.py`), запоминает места блоков.
3. Запускает Dota в демо-режиме героя, выбирает героя мышью, снимает экран и закрывает игру (`dota_session.py`).
   Снимок игры без мода хранится в `cache/ingame_base/` и снимается заново только после обновления Dota.
4. Ищет каждый блок на скриншоте игры с модом и сравнивает с местом на сайте (`compare.py`).
   Расхождение больше 4 px — ошибка. Картинка-отчёт: зелёное — сайт, красное — игра.

Нужно: Steam с Dota 2, `grim`, доступ к `/dev/uinput`, `nix` (python-evdev, opencv, playwright, node).
Во время прогона (3–5 минут на героя) не трогайте мышь и клавиатуру: игра на экране.
